# HaiTO 実仕様 ↔ MAMOR-AI 整合メモ

## 判明したこと
**HaiTO**（ヒトトヒトHDグループ, 2025-05資料）は、MAMOR-AI が再開発している実プロダクトそのもの。中核は「**インシデント × ポジション**」ごとのリスク予測AI（商業施設・興行施設・興行運営の3業態モデル）＋直感ダッシュボード＋情報共有DX。

## 既存の当システムとの一致
| HaiTO | MAMOR-AI（実装済み） |
|---|---|
| リスク予測（分類/場所/リスク度/発生確率/要因/詳細情報） | `RiskItem { type, position, score, probability, factors, level }`（Sprint2 実装済・テスト済） |
| リスク度ランキングTOP5 | `rankRisks` / リスク画面 |
| ポジション別・時間帯別リスクレベル | `filterRisks`（type/position）＋要拡張（時間帯軸） |
| 生成AIによるリスク説明文（GPT-4o-mini） | サーバの Claude 秘匿ゲートウェイ（`/api/risk`）で置換可 |
| 一斉共有／重要事項／業務指示 | `notify`（種別×対象の配信・未確認集計, Sprint4 実装済） |
| 日報→データ蓄積→予測精度向上 | 日報テンプレ（counter=インシデント）＋集計＋マスキング |

→ **アーキテクチャは既に HaiTO の形に一致**。差分は「3業態マスタの投入」と「時間帯軸・AI条件（特性/共通/特殊）のフィールド化」。
